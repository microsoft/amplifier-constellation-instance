# Working on Instance

Read [the vision](docs/VISION.md), then select the relevant boundary from the
[contract map](contracts/README.md). Shared promises and collaboration practice
live in the [Constellation umbrella](https://github.com/microsoft/amplifier-constellation/blob/main/AGENTS.md);
apply them without copying a second methodology or family contract here.

Inspect current source, configuration and meaningful checks for the next outcome.
Preserve exact protocol definitions in their existing homes. Guides and the
bundled administration client add no separate promises about future products.
Keep release history, private deployment evidence and a maintained gap inventory
out of the normal onboarding path.

Use [validation](docs/validation.md) for checks appropriate to the change. Check
both producer and consumer when their shared behavior changes. Documentation
changes need link and meaning review; no live operations follow from a
documentation assignment.
