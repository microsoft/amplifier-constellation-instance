Remove the certificate warning

Install this agent’s certificate once on each device you use. This lets your browser recognize the installation.

Download certificate

Only install a certificate from an installation you recognize. Compare its fingerprint with the installer’s output, or ask the person who installed it.

  1. Open the downloaded .crt file and choose Install Certificate.
  2. Select Current User, then Place all certificates in the following store.
  3. Browse to Trusted Root Certification Authorities. Complete the wizard and confirm the certificate you recognize.
  4. Close all Microsoft Edge windows, reopen Edge, and return to the secure page.

If your organization manages certificates, your IT team may need to install it.

  1. Open Keychain Access using Spotlight (Command–Space). Select the login keychain.
  2. Drag the downloaded .crt file into Keychain Access.
  3. Double-click the Agent Instance certificate, expand Trust, and set Secure Sockets Layer (SSL) to Always Trust.
  4. Close the certificate window and confirm with your Mac password if asked. Fully quit Microsoft Edge (Command–Q), reopen it, and return here.
  1. In Edge, open Settings and search for certificates. Open the certificate manager (you can also type edge://settings/certificates in the address bar).
  2. Under Authorities or Custom certificates → Trusted certificates, import the downloaded .crt file. If asked, allow it to identify websites.
  3. Completely close and reopen Edge, then return here. Labels vary by browser version.
