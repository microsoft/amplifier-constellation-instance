# Optional interfaces alongside ACP

The single [Instance interface map](../contracts/README.md#technical-interfaces)
locates ordinary ACP, management, context, participation, work and lifecycle
specifications. Use each serving definition for version discovery, enabled state,
authority, errors and fallback behavior.

The [hosting agreement](../contracts/hosting.md) states Instance's local promises;
[Constellation](https://github.com/microsoft/amplifier-constellation/blob/main/contracts/README.md)
owns shared behavior. This page preserves existing navigation links and adds no
wire fields or requirements.
