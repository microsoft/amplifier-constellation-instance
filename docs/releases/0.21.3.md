# Agent Instance 0.21.3

Attention now asks whether an input needs consideration, including a correction,
changed dependency, or answer that needs no public acknowledgment. The shorter
policy distinguishes the evaluated agent from the sender and addressee, and
checks whether later conversation already resolved the need. The provider gets
ID references to the evaluated agent and original trigger while the source
exchange remains intact and ordered.

The existing decision provider, confidence handling, admission budgets, tickets,
source-delivery records, and tool permissions are unchanged. An uncertain input
can still receive bounded review; the engine decides whether to speak or act.
This release neither grants new work authority nor replays a previously handled
source. Attention quality remains model-dependent; isolated evaluations do not
establish sustained conversation quality for every installation.

Original sessions, selected engines, credentials, and installation settings are
preserved. Upgrades use the enrolled connection lifecycle.
