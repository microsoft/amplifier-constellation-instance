# Agent Instance 0.22.13

Compatible connectors can now supply the conversation orientation once. Instance
still validates the exact conversation grant and retains its memory, current work
and responsibilities; a mismatched or unsupported connector marker uses the
existing full orientation. Stable context precedes the current request, avoiding
duplicated Slack history without dropping that request or changing its authority.

Windows consumer setup and background helpers now use launch paths that do not
create terminal windows. The Instance startup entry joins an existing terminal
only for interactive command-line use; redirected input, output and error
streams remain available to its clients. Model account setup, configuration and
ACP connections keep their existing process ownership, limits and permissions.

The independent Windows update helper uses the private, checksum-verified
windowless Python shipped in the complete consumer bundle. Existing Windows
installations must first receive that verified bundle through the normal update
path before reenrolling the helper. A missing or changed private interpreter
refuses enrollment instead of substituting a system Python. Existing task
identities, selected engines, settings, credentials and sessions are preserved.

Fresh installations continue to bundle Runtime 0.15.12. Existing installations
manage their selected Runtime separately through its enrolled updater. This
release does not alter approval choices, tool authority, update admission or
work budgets.
