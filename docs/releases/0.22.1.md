# Instance 0.22.1

Windows updater setup now registers the helper for the same logged-in owner as the agent, using a limited interactive principal and an owner-only logon trigger. This fixes an access-denied setup failure on an ordinary unelevated Windows 11 desktop without requiring an administrator launch.

The native startup fixture checks both actual registered task definitions, including on elevated CI accounts. Existing installation identity, configuration, model selection and update enrollment remain intact. The bundled default runtime remains 0.15.4.
