# Agent Instance 0.22.15

Owners can issue a dedicated ACP credential for one registered HTTP MCP server
that uses no credential headers. The credential binds the server’s name, URL
and optional flag. Adding another server leaves the grant limited to the
original descriptor. Changing that descriptor, revoking the credential or
reaching its expiry ends access.

A client using the credential must still present its conversation’s own
authorization to reopen a group session. Sessions that previously required
full tool access continue to require it. See [Tool connections](../tool-connections.md#one-registered-server)
for setup and revocation details.
