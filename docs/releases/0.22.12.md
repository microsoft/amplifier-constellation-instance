# Agent Instance 0.22.12

New installations bundle Runtime 0.15.12. It keeps Anthropic reasoning only
when the model view still matches the instructions, tools and earlier messages
that produced it. Refreshed context arriving at a request boundary is projected
with the request that carries it. The full saved conversation remains intact.

Existing installations retain their selected engine, model, credentials and
sessions. Their enrolled engine updater manages Runtime separately from
Instance. Approval settings, tool restrictions and work budgets are unchanged.
