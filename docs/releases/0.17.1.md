# Agent Instance 0.17.1

New native installations now use Runtime 0.11.1. The OpenAI Responses service does not accept steering when automatic compaction is requested. This runtime uses explicit native compaction at settled response boundaries, preserves queued updates and the original turn budget, and continues accepted steering on its existing response chain.

Existing native installations should update the enrolled runtime component as well. The instance keeps its source-delivery, maintenance and observability contracts from 0.17.0; this patch changes the packaged native runtime pin only.

Validation: live OpenAI tests cover compaction plus two ordered mid-turn updates and exactly one file write. Runtime protocol regressions cover updates arriving during maintenance and accepted steering at a compaction boundary. Installation/provisioning checks and all supported platform CI builds validate this package.
