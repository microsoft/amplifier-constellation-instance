# Agent Instance 0.21.1

Prepared service connections can conditionally enable their own context provider
without overwriting concurrent changes to other providers. The new admin PATCH
compares the exact expected target and changes only its enabled flag under the
same writer lock as registry PUT. Missing or changed targets return conflict.

The capability is explicitly advertised. Domain owners retain one-use setup
provenance, connection gating, service lifecycle and lost-acknowledgment recovery.
No provider, model or service call is made by this metadata operation. Existing
saved connections, selected engines and task authority are unchanged.
