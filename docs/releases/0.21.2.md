# Agent Instance 0.21.2

Attention admission failures can now carry a negotiated, request-bound `not_forwarded` outcome. Experiences can distinguish a refused optional input from uncertain execution without interpreting an error code or message. This does not settle previous effects, complete a task or authorize retrying an offer. Backend errors cannot impersonate this host-owned marker. See the [attention contract](../attention.md).

Session history loads no longer write diagnostic state for every history notification. Replay activity is sampled once per second, with a terminal count and duration. All history notifications, authorization checks, saved sessions and ordinary prompt observations remain intact. A disposable 2,048-frame fixture improved from 13.51 seconds to 0.22 seconds; actual installation performance depends on its history, backend and storage.

Existing installation settings, selected engines, credentials and work authority are preserved. Upgrades use the enrolled connection lifecycle; this release does not enable new task permissions or configure trusted MCP endpoints automatically.
