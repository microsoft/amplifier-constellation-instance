# Agent Instance 0.22.11

On macOS, updates wait for the previous service to finish unloading before
starting its replacement. This prevents a completed stop request from racing
with the next start and causing an otherwise healthy update to roll back.
The independent update helper uses the same check when it is refreshed.

Engines can now explicitly identify which current, one-time approval choice
Automatic should use when they offer several different choices. This requires
an engine that supports the optional negotiated extension. Existing engines
with one ordinary choice keep their current behavior; an ambiguous request
without that support still asks the person.

This does not enable Automatic, change an engine's access mode, create
remembered rules, or expand tool permissions and budgets. Instance remains
the agent's single policy owner. Existing sessions, selected engines and
credentials are retained. The bundled Runtime remains 0.15.10.
