# Agent Instance 0.22.14

Prompts carrying source-delivery metadata now keep configured agent identity,
instructions and profiles ahead of the changing original-input reference. The
reference follows the connector's prompt and authorized conversation orientation,
preserving the existing order of those blocks.

The reference still identifies the original input; it does not accept work or
grant authority. Source receipts, audience checks and duplicate-input refusal
retain their existing behavior. This correction does not claim a measured
provider cache or token-cost improvement.

Fresh installations continue to bundle Runtime 0.15.12 with the same six platform
pins. Existing installations keep their selected engine, model, credentials,
settings and sessions through the normal update path. The windowless Windows
setup and private helper behavior introduced in 0.22.13 remain unchanged.
