# Agent Instance 0.21.0

Saved service connections are now independent of live ACP clients. Connections
shows saved entries and their observed state, offers Connect/Disconnect, and
renders an optional typed Add form or the domain setup link.

The existing installation host helper executes only fixed owner-enrolled commands.
Durable operation IDs, status-only reconciliation and acknowledged context
handoffs preserve active work through Disconnect and original-session verification
through Connect. Context provider enabled state is independent and remains in
force. No arbitrary shell, credential-in-form, ACP extension or engine change is
introduced.

Installations must enroll compatible domain providers before controls appear.
Existing-only services can omit Add until actual setup is available. Adding a
connection does not enable work policies or automatically enroll its updates.
Unknown operations remain visible and block overlapping changes; reconnection
never renews expired task authority. See [the complete contract](../service-connections.md).

Validation includes actual local API/browser tests, host worker subprocess tests,
and domain boundary fixtures. Publication is separate from owner enrollment and
live interaction verification. Native engine and external ACP backend selections
are unchanged by this release.
