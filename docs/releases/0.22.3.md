# Instance 0.22.3

Concurrent administration edits preserve newer shared values and unsaved local
text. Compatible changes reconcile through the existing view API; queued local
edits retain their order, and form cleanup preserves later drafts.

The optional source-delivery profile now links ordinary inputs to responsibilities
through existing receipts and work records. Callers can recover work after a lost
reply using per-creation retry keys. One input can produce several work items;
creation, acceptance and completion remain separate. Same-conversation handoffs
retain original attribution and current access checks, without replaying unknown
or already-incorporated inputs.

Runtime and dependency pins are unchanged. Enrolled updates preserve selected
engines, models, credentials, sessions and work through existing lifecycle controls.
See [consumer bundle validation](../validation.md#consumer-bundle-validation)
for platform packaging and startup coverage.
