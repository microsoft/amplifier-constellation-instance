# Instance 0.22.6

Optional investigation turns now share the overall attention allowance unless an
installation explicitly configures a smaller investigation allowance. Omitting
`uncertain_turns_per_hour`, or setting it to `null`, no longer adds a default
12-turn hourly restriction.

Existing numeric settings, including zero, keep their meaning. Overall limits,
spent allowance, held inputs and admission checks are unchanged; updating does
not replay inputs or rewrite an installation's policy. See
[attention policy](../attention.md) for configuration and accounting.

For a downgrade, older versions require a numeric setting to preserve equivalent
behavior: use the overall hourly allowance when no separate investigation limit
is wanted. Older versions default an omitted setting to 12 and reject `null`.

The existing updater, Runtime 0.15.6 and dependency pins are unchanged.
