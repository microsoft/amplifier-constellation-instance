# Instance 0.22.4

External `context_read` now forwards an explicitly supplied nonnegative integer
`before` position to the selected conversation source. Supporting sources return
`source.next_cursor` for the caller's next request in the same conversation and
thread. Each page retains existing access checks, source attribution and coverage.
Paging remains caller-driven, and unsupported continuation errors stay visible.

Native history behavior, Runtime 0.15.6 and dependency pins are unchanged. See
[external conversation continuation](../conversation-continuity.md#provider-contract-agent-instancecontext1)
for the optional source contract and its limits.
