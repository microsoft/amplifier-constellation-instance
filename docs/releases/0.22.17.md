# Agent Instance 0.22.17

On Unix, a single-owner installation can choose the optional Codex app-server adapter as its external engine. The adapter uses a locally installed Codex and its dedicated signed-in profile. Download `codex-app-server-adapter.pyz` and its matching checksum from this release. The [adapter guide](../../prototypes/codex-app-server/README.md) covers configuration, supported clients and recovery of original images.

Installation owners can also enable automatic idle installation for individual components while keeping the rest of the installation on **When requested**. Hourly checks continue to show available updates for every enrolled component. See [update scheduling](../updates.md) for the registration setting.
