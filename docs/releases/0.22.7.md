# Instance 0.22.7

New native installations use the published Native 0.15.7 engine. All six consumer
packages carry its exact binary and complete release archive, so offline setup
starts the same qualified version without fetching an older engine first.

The consumer check binds the package's engine lock, version and hashes to the
release source, then verifies the actual installed default engine. It rejects a
self-consistent older package, a missing advertised engine and changed bytes.

This changes the packaged default for new installations. Existing installations
retain their selected engine, model, accounts, configuration, sessions and work;
their engine updates still use the installation's normal update path. The private
Python and other dependency pins are unchanged.
