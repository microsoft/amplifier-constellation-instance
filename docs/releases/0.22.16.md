# Agent Instance 0.22.16

In the Instance web editor, **Model & capabilities** now lists the models
available to the connected ChatGPT account. The saved model remains visible
under **In use**. If the account returns no selectable models or the request
fails, choose **Retry** to check again. Providers without model discovery
continue to accept an exact model or deployment name.

Use **Save engine settings** to apply a selection. If the connected account
changes after the list was loaded, Instance preserves the draft and asks you
to refresh the list before saving the new model.

New native installations use Constellation Runtime 0.15.15. Its live account
model list identifies choices that require an explicit unverified-model opt-in.
