# Instance 0.22.2

Setup can enroll an existing installation's updater without racing its active
work. An idle updater hands off ownership through the existing local locks;
reenrollment preserves its journal and holds new work until restart completes.
Active or uncertain update and connection work remains with its original owner.
Worker startup also takes its lifetime lock before reading the journal.

New installations bundle the published Constellation Runtime 0.15.6, verified
by archive and executable checksums on all six supported targets. Updating an
existing Instance preserves its selected engine, model, credentials and history.
The installer, lifecycle protocols and setup commands are unchanged.

See [consumer bundle validation](../validation.md#consumer-bundle-validation)
for the package and native startup checks and their desktop-account limits.
